COURIERPILOT — VERSION WEB INSTALLABLE

Cette version est préparée comme une Progressive Web App (PWA). Pour que Chrome propose « Installer l'application » ou « Ajouter à l'écran d'accueil », les fichiers doivent être hébergés sur une adresse HTTPS.

IMPORTANT : ouvrir index.html depuis le stockage du téléphone ne suffit généralement pas pour installer une PWA. Ce ZIP n'est pas un APK.

Étapes une fois hébergée :
1. Ouvrir l'adresse HTTPS dans Chrome sur le Samsung.
2. Menu ⋮ > Installer l'application (ou Ajouter à l'écran d'accueil).
3. Les données restent stockées localement dans le navigateur de cette application ; exporter une sauvegarde régulièrement.

Le taux de prélèvements par défaut est 28,38 %, selon le taux indiqué par l'utilisateur. Les frais Avalon additionnels sont à 0 % par défaut.
